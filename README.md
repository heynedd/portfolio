## ✦ Features

| Feature | Detail |
|---|---|
| 🎯 Custom Cursor | Inner dot + outer ring, both in `#c93d3d`, follow mouse with lag |
| 🌗 Bilingual | Toggle **EN / ID** — semua teks punya `data-en` dan `data-id` |
| 📊 Skill Bars | Animated on scroll via `IntersectionObserver` |
| 🕸 Radar Chart | Canvas-drawn spider chart, 6 skills, gradient fill |
| 🖼 Photo Frame | Corner accents in gold, badge overlay (OTW, GPA, Projects) |
| ✨ Scroll Reveal | Elements fade + slide up on enter viewport |
| 📱 Responsive | Single column on mobile, photo still visible |
| 🔖 Scrollbar | 3px custom `#c93d3d` scrollbar |
| 🔡 Roman Numerals | Giant faded section markers (I–IV), `opacity: 0.03` |

## ✦ Tech Stack

```
No frameworks. No dependencies. Just:

  HTML5 ──────── Structure & semantics
  CSS3  ──────── Layout, animation, custom properties
  JS    ──────── Cursor, reveal, radar chart, lang toggle
  Canvas────────  Radar/spider chart drawn with vanilla 2D API
  Google Fonts ── Cormorant Garamond + Syne
```
