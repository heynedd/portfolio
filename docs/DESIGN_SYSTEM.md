# Design system — Information in motion

An editorial working notebook: oversized dark typography, cobalt visual punctuation, real project documents, fine rules and generous quiet space. The opening moves from an idea to a usable form; subsequent chapters show the evidence.

- Paper: #f5f5f2. Ink: #16181b. Accent: #0052ff. Secondary text: #60636a.
- Space Grotesk for display; DM Sans for reading; system fallbacks preserve usability offline.
- Body copy 16–18px; useful navigation 14px; secondary metadata at least 12px.
- Layout gutter: clamp(22px, 5vw, 88px). Reading width approximately 65 characters.
- Square media frames; preserve whole source images. No uniform project-card grid.
- Rajawali: large portrait document with sticky editorial note. SKD: wide system showcase. Rafflesia: offset portrait editorial. PKM: dark knowledge chapter.
- Focus: high contrast outline, visible on dark and light surfaces. Real anchors and buttons.
- Mobile: stacked document stories, compact hero visual, static sticky columns; native scroll remains available.
